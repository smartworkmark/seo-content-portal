The problem

A recommendation without context is a guess.

Before V3
  • ✕ Saw a "No change" flag with no reason — was the agent right, or did it miss something?
  • ✕ Couldn't tell if a campaign was hitting budget every day or coasting at 30% utilization.
  • ✕ "Budget increase" recommendations on accounts already over-spending — no warning.
  • ✕ Investigated empty campaign tables only to discover the issue wasn't budget at all.
After V3
  • ✓ Every "No change" carries a one-line reason ("Demand-side issue", "Not budget-constrained", etc.).
  • ✓ 7-day utilization bar visible on every campaign — orange / green / blue at a glance.
  • ✓ ⚠ icon flags any recommendation that runs counter to the account's pacing direction.
  • ✓ All-demand-limited accounts get a banner pointing the reviewer at targeting / bids, not budget.

Deep dive 3

Supervisory, not actionable.

When the agent recommends an action that runs counter to the account's pacing direction (e.g. campaign-level increase on an over-pacing account), it flags the row with a ⚠. Hover reveals a tight, supervisory tooltip — for visibility, not action.

Performance Max — General Dentist ⚠ budget-limited
Flagged: counter to account direction
For visibility — no action needed

Why the wording matters. Earlier drafts read "Conflicts with account direction" — which sounds like the reviewer needs to fix something. The agent has already weighed the trade-off and made the call; the reviewer just needs to know it happened.

The two-line tooltip — one line of identification, one of explicit reassurance — keeps the cognitive load low while removing the false-positive interpretation.

Design principle

Every metric earns its screen space by changing a decision.

We deliberately did not bolt on every available signal. Each new field appears only where it changes how the reviewer reads the row — and stays out of the way the rest of the time. The result: more signal, less noise.

Examples of conditional display
  • • "% IS lost" only on budget-limited campaigns above 1%
  • • Util bar hidden during month-start grace (would mislead)
  • • Conflict ⚠ suppressed on "No change" rows
  • • Mixed-account chip only when classifications actually mix
  • • Feedback form hidden on on-track and grace accounts
What that means for the reviewer
  • • Faster triage — eyes land on what changed
  • • Higher trust — the agent shows its work
  • • Fewer false alarms — supervisory framing on warnings
  • • Less context-switching — every "why" is in the row
